# Provenance

This is a curated publication of my local Unity Top Down Workshop project. The original folder contained my workshop code alongside third-party art, audio and editor packages, vendor sample scenes and planning documents.

The public source retains the 28 original workshop runtime/editor C# files, with publication fixes and a small amount of supporting code. It excludes the vendor directories and copied prefab collection: all 244 images under the original workshop prefab folder matched images in the bundled art pack byte-for-byte. No vendor sample levels are presented as my level design.

Publication work added neutral sprite defaults, two starter scenes generated through the existing mission wizard, package-independent setup, separate assemblies, documentation and tests. It also repaired weighted pickup accounting, inactive-key lookup, full reset behavior, goal collider sizing and stopping residual movement on completion. Original planning DOCX files and personal project metadata are not included.

The Git history starts at this curated publication. My original local project remains separate. This repository demonstrates editor tooling, reusable gameplay components and a workshop workflow; it makes no claim that the underlying Unity engine, commercial art packs or measured educational outcomes are my work.
